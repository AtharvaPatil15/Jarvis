## Root cause (D-020)
In both failures the first streamed sentence is missing. `on_delta` hands released sentences to the queue with
`loop.call_soon_threadsafe(...)` (runs on a later loop turn), while `produce()` put the flushed remainder and the `None` end
marker with `put_nowait` immediately, so they overtook it. A standalone reproduction of that pattern:
```
mixed scheduling order: ['Done.', None, 'Sure.']
single channel order:   ['Sure.', 'Done.', None]
```
Fix: `produce()` now uses `loop.call_soon_threadsafe(sentences.put_nowait, ...)` for its sentences and the end marker. The
tests were not changed.
