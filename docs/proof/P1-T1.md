# Proof — P1-T1: Server app factory, ordered event hub, crash fix, `FakeLLM`

- Date: 2026-09-14 05:32 (local)

- Base commit before this task: `c46818f` (`git rev-parse --short HEAD` before starting)

## What changed
- `assistant/hub.py`: new `ConnectionHub` — FIFO ordered fan-out to every WebSocket, callable from any thread.
- `assistant/brain/fake_llm.py`: new deterministic `FakeLLM` with `chat`, `embed`, `health`, and temporary `generate`.
- `assistant/brain/llm.py`: added `ToolCall`, `ChatResult`, `LLMError` types and `LocalLLM.health()`.
- `assistant/orchestrator.py`: constructor accepts injected `llm`.
- `assistant/voice/voice_controller.py`: added `conv_manager` and set `is_processing` before dispatch (crash fix).
- `server.py`: rewritten as `create_app()` factory (nothing built at import time), voice start guarded so it never crashes the server, `/health`, `/ws`.
- `start_backend.py`: rewritten to run the factory.
- `scripts/backend.ps1`: background server start/stop helper used by later proofs.

## Tests written
- `tests/unit/test_hub.py` — FIFO order, cross-thread emit, failing-socket drop, enum serialisation.
- `tests/unit/test_fake_llm.py` — echo reply, script consumption, on_delta chunks, embeddings, health.
- `tests/unit/test_server_app.py` — import builds nothing, health, WS tracking, cross-thread emit, voice crash tolerance.
- `tests/unit/test_legacy_voice.py` — legacy `VoiceController` exposes `conv_manager`.
