# Proof for P5-T5: MCPBridge — use any MCP server's tools

## Summary
Implemented `MCPBridge` that starts MCP servers from `mcp_servers.json` on a private event loop, exposes their tools as `mcp__<server>__<tool>` in the registry (permission required by default), and handles server failures gracefully. Proven against a local echo test server and the official filesystem server.

## Acceptance Criteria Met
✅ MCP servers from `mcp_servers.json` start with backend
✅ Tools appear in registry as `mcp__<server>__<tool>` with permission required by default
✅ Agent can call real MCP tools end-to-end (verified by e2e tests)
✅ One failing server never disables others or the backend (verified by `test_a_broken_server_does_not_block_the_others`)
✅ Tools are callable by the agent with permission flow (verified by `test_server_registers_mcp_tools_at_startup`)
