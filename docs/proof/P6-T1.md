### 2. Implement `store/assistantStore.ts`
Rewrote with new fields: `streaming`, `appendResponseDelta`, `endStream`, `connected`, `setConnected`, `pendingPermission`, `setPendingPermission`, and `PermissionRequest` interface.

### 3. Implement `lib/socketEvents.ts`
Extended `SocketActions` interface and `applyServerEvent` to handle:
- `ai_response_delta` → `appendResponseDelta`
- `state_change: thinking` → `endStream`
- `state_change: idle` → clears pending permission
- `permission_request` → stores request
- `tool_end` → clears pending permission
- `reminder` → shows in transcript

### 4. Create `lib/jarvisSocket.ts`
New resilient WebSocket client with:
- Exponential back-off reconnection (capped at maxDelayMs)
- Message queueing while disconnected
- `sendUserText` trims and validates
- `respondToPermission` sends permission_response
- `close()` stops reconnection attempts
