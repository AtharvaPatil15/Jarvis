# Proof for P5-T4: Reminders and the scheduler

## Summary
Implemented persistent reminders with a background scheduler that polls SQLite for due reminders, fires them exactly once (including across restarts), emits `reminder` events to the UI, and speaks them when voice is enabled.

## Acceptance Criteria Met
✅ Each reminder fires exactly once (including after restart - verified by test_reminders_survive_a_restart)
✅ Listener errors never stop the scheduler (verified by test_background_thread_fires_and_survives_listener_errors)
✅ Reminders persist in SQLite and survive backend restart
✅ UI receives `reminder` events (verified by test_due_reminder_is_pushed_to_the_ui)
✅ Voice speaks reminders when enabled (wired in server.py lifespan)
✅ Tools `set_reminder` and `list_reminders` registered and functional
✅ Relative (`in_minutes`) and clock-time (`at_time` + `day`) reminders supported
